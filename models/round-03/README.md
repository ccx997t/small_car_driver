# R03：轮组尺寸落实、整车组合与升降检查

日期：2026-11-16。状态：第三轮评审版本，非工程定稿。

## 查看

运行项目根目录 `./scripts/open-freecad-r03.sh`，使用小车独立配置打开：

- ChassisAssembly_R03.FCStd：整车上轨组合，143个实体，透明侧板与底板用于看清内部。
- DriveModule_R03.FCStd：单套驱动模块，独立于整车布局，作为连接与升降评审文件。

两份文件均有STEP。显示配色.FCMacro负责可见性、配色及预览生成。

需要交互升降时，在FreeCAD运行本目录“升降演示.FCMacro”：滑块范围-4至+4mm，仅控制单套模块的随动件及弹簧几何；关闭对话框恢复中位。整车组合是中位的静态几何副本，不随滑块联动。不自动保存演示位移。

## 使用初稿资料的部分

- 底盘长1400、宽750；驱动轮X=0；轨道轮X=±450；万向轮转向轴X=±600，滚动轴X=+580/-620。
- 轮轨压轨线Y=±275；万向轮转向轴Y=±365；双轨Ø50、中心距550。
- 取轨顶Z=0：内底板下表面Z=50，侧板下缘Z=20，驱动轮/轨道轮轴心Z=70。
- 驱动大外轮Ø248×54，小内轮Ø140×55；轴向内端在压轨线内侧25，交界在外侧30，大外侧在外侧84。两侧总外宽718。
- 驱动轮交界采用R25：小轮面沿轴向外侧5处开始过渡，在外侧30处达到半径95，再进入大外轮侧面。轴孔/内部轮毂仍简化，非现成产品内部设计。
- 轨道轮小轮面Ø140×54、裙边Ø190×35；按圆弧起点外偏2建立R25过渡，轴向分段按当前图义解释，仍需真实截面确认。
- 万向轮Ø80×20，偏置20；轮轴Z=-14，轮底Z=-54，与驱动大外轮底同高。平地运行用途仍待确认，不将同高关系当作工况确认。

## 相对R02的结构变化

- 两侧驱动模块电机均朝内；采用镜像处理横向安装关系。
- 两套模块通过贯通横梁与侧框包络连接，避免各自局部车架互相悬空。
- 原架近似几何保持原形体，仅改变装车位置；没有新增原架孔。
- 新增可拆端部压板、两点压紧螺栓及下承托防脱唇。压紧螺栓位于新增适配件区域，避开原架主体。
- 新增导向轴端保持环，保留独立限位。轴端实际锁紧和螺纹结构仍未完全实现。
- 内底板补驱动、轨道轮开口；侧板补万向轮避让口。开口尺寸、底板厚度5mm、局部梁截面及新孔均暂定，不代表获准加工实车。

## 验证与结果

- 两份FCStd均已在FreeCAD1.1.4保存、重新打开及重算，143个整车实体拓扑有效。
- 整车中位逐对检查10153对，未检出大于0.05mm³的实体重叠，详见assembly_overlap_check.json。不检出重叠不证明有连接、紧固或承载能力。
- 单模块移动对固定件在-4、0、+4mm采样，未检出超过阈值的相交。排除弹簧、线缆；未覆盖移动件相互接触、全部中间位置和整车运动。
- GUI滑块已程序化运行三个位置：轮心Z分别66、70、74，弹簧固定端顶面约150，详见motion_gui_check.json。
- 弹簧随动仅重建螺旋外形，不计算刚度、预压、压并、应力或动力学；±4mm是演示位移，不能作为额定行程。
- 实际FreeCAD视图：ChassisAssembly_R03_isometric.png、DriveModule_R03_isometric.png、assembly_bottom.png及motion_*。

## 尚未解决/仅作暂定表达

- 壳体高度300的基准：暂从侧板下缘Z=20起计，到Z=320，不是用户确认的总高定义。
- 黑色架仍为照片近似；端部压紧面、预紧力、压板强度、防滑能力、螺纹/螺母、防松及工具空间未验证。
- 新增压紧螺栓为圆柱占位，未建螺纹和锁紧螺母；不得视为可靠夹紧已经完成。
- 导向补偿侧未实现浮动机构，普通圆轴套不等于已解决双轴卡滞。
- 弹簧座固定、限位锁紧及导向轴端保持只有几何表达，未达生产细化深度。
- 轨道轮仍为轮体占位，没有完成轮轴、轴承座和与车架的安装支架；整车轮组完整不代表所有轮已具备实装连接。
- 万向轮叉架及安装座简化；尚未检查360度转向扫掠和紧固孔。
- 线缆在单模块中保留曲线占位，整车组合暂不复制；固定/活动线夹、接插件、疲劳弯曲和拆装路径未完成。
- 无载荷和实际安装孔数据，没有完成承载、轮载分配、弹簧选型、牵引或行驶验证。

## 可编辑性与复现

主体是独立Part形体；参数表记录来源，尚未实现完整尺寸联动。用build_model.FCMacro统一修改重建，生成会覆盖本目录同名输出，人工修改先另存。修改轮组参数需要同步更新截面生成代码。

命令行生成后运行check_assembly.FCMacro导出单模块STEP并检查中位整车相交；随后运行显示配色.FCMacro保存GUI样式和演示验证记录。检查脚本使用相同FreeCAD环境。

R01、R02文件未修改，R03作为独立评审版本归档。

## 同文件展示切换

运行“组合展示.FCMacro”打开 Presentation_R03.FCStd，并显示“查看局部驱动 / 查看整车组合”按钮。文件内含两个独立展示分组，默认显示局部驱动；整车分组的双轨、四个万向轮及叉架安装座隐藏，原对象保留。展示形体是创建时的副本，后续源模型变更不会自动同步。

“打开局部与整车.FCMacro”则以两份独立文档打开原模型，供底部标签切换；“隐藏轨道和万向轮.FCMacro”可恢复当前简化展示状态。
