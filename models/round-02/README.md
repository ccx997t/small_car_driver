# 驱动模块 R02：局部车架对接方案

本轮为结构评审模型，所有尺寸暂定，不作为加工或选型依据。第一版保留在 models/round-01。

## 相对第一版的变化

- 用局部空心梁框架取代整块顶部占位板，区分车架与模块支座。
- 增加左右可拆卸安装法兰、安装孔、螺栓、加强肋、上下导向轴端支座。
- 取消原绿色活动横梁和中部连接耳，改为黑色架端部适配座承接导向轴套。
- 黑色架的 BRep 几何构造与 R01 一致，不改原有近似孔槽；这仍然不是实测原件模型。
- 增加车外轮槽护板、线缆活动余量占位。护板不是承载件，暂不设计其固定附件。
- 弹簧与上下弹簧座在静态模型中接触；设置独立限位环。线圈端部仍简化，弹簧未完成选型。
- 轮外圈、轮毂和轴分开表达，消除旧版简化外形的实体相交。

## 方向

模型坐标：X 沿车体前后方向；+Y 车外；-Y 车内（电机侧）；+Z 向上。Front 视图按车内侧观察。此为当前设计约定，不能当作原实物已测坐标。

isometric.png 为内侧轴测视图；outside.png 为外侧视图；inside.png 为内侧正视图。预览来自实际 CAD 网格，不是 FreeCAD 截图。

## 仍未确认的接口

1. 黑色架端部是否本身用于导向：仍待确认。本轮使用新增端部适配座包络绕开原孔，不假设原孔可直接选配轴套。
2. 端部适配座当前只表达包络与承托位置，夹紧、定位、防滑、防脱及紧固件尚未细化。不能视作已实现可靠连接。
3. 双弹簧示意与实物的对应关系：仍待确认。
4. 局部车架形状、梁壁厚、孔位及位置全部暂定，未证实真实小车具有同样的梁和接口。
5. 右侧导向预留横向补偿的选型意图，当前形体仍是普通圆轴套，没有实现浮动机构，不能认定防卡滞问题已解决。
6. 下限位到活动座静态距离约8 mm；这不是允许工作行程。上限、弹簧压并、预压、离地高度和路面跟随能力均待校核。
7. 线缆只是空间占位，未实现接插件、应变释放和线夹固定。

## 校验

FreeCAD 1.1.4 生成并导出 STEP；保存后重新打开和重算，45 个形体均有效且各含一个实体。

本轮对45个实体逐对进行包围盒筛选和实体交集检查，当前静态位置未检出大于0.05 mm³的重叠。见 geometry_check.json。静态不重叠不等于连接可靠，也不代表上下运动无干涉。尚未完成全行程、承载和制造验证。

## 查看与编辑

打开 DriveModule_R02.FCStd；若需要配色和视图居中，在 FreeCAD 中运行本目录 显示配色.FCMacro。宏仅针对 R02，设置各分组及实体可见、车外护板半透明，并切轴测视图。

已定位并修复当前环境缺少 DISPLAY 导致的 Qt xcb 启动失败：显式连接本机 DISPLAY=:0 后，桌面 FreeCAD 成功打开 R02，已通过桌面截图确认模型显示。此次启动失败发生在加载模型之前，不足以解释此前所有崩溃。后续运行 `./scripts/open-freecad-r02.sh`，自动补齐显示环境并使用小车独立配置；未改全局或温室配置。

简单长方体、圆柱可直接修改自身参数。带孔支座、原架、弹簧、空心梁等为独立 Part::Feature；通过 build_model.FCMacro 修改重建。参数表大部分为设计记录，只有轮尺寸曾做部分关联，R02轮改为分离实体后需在宏里统一修改尺寸；不具备全装配参数联动。宏重建会覆盖同名输出，人工修改请先另存。
