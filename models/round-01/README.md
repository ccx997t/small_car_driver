# FreeCAD 驱动模块 R01

已用本机 FreeCAD 1.1.4 生成 DriveModule_R01.FCStd 和 STEP；保存后重新打开、重算，40 个部件实体全部通过几何有效性检查。检查记录见 geometry_check.json。没有完成运动装配、全行程干涉、载荷和制造验证。

## 打开与查看

直接在 FreeCAD 打开 DriveModule_R01.FCStd，按 V、F（依次按）适合窗口。模型按固定框架、活动过渡件、已有架、驱动组件、导向、弹簧、紧固件分组，可隐藏局部底盘或电机查看连接。

本次在命令行生成，文件未保存 GUI 显示样式。若打开为默认灰色，可在 FreeCAD 的“宏 → 宏”中选择并执行同目录的“显示配色.FCMacro”，应用配色并保存视图。它只针对本模型，不改变全局偏好。

isometric.png 与 rear.png 根据实际 CAD 实体网格绘制，不是 FreeCAD 窗口截图。

## 本轮模型边界

- 黑色架保留中央圆接口、周边孔、端部开口的特征意向；外形及孔数尺寸均属照片近似，没有实测，不可用作原架制造图。
- 模型中的新增过渡耳、紧固件为接口意向，不代表已有孔位已匹配。不得据此修改原架。
- 尺寸单位 mm，全部暂定：轮径 150、轮宽 40、导向轴直径 16、双轴间距 200、底盘安装面高度 275；这些数值仅形成可评审比例，不是从照片量取的实测结果。
- 轮电机为简化外形；双弹簧为真实螺旋实体，刚度、预压及端面形式未定。
- 结构是静态摆放，尚无运动约束求解及可操作悬挂自由度。
- 形体有效不等于装配成立；限位、轴套、紧固和过渡连接仍须细化。
- 制造工艺和材料不定。

## 可编辑性

参数表带有少量表达式连接，可修改轮半径、轮宽、轮心高度、导向轴半径与位置等。矩形及圆柱标准形体可直接编辑自身参数。黑色架、带孔座及弹簧是独立 Part::Feature 实体，复杂几何通过 build_model.FCMacro 源代码修改并重新生成。

这不是完整联动的参数化总装：单独改变轮径、轴间距或高度不会自动调整所有相邻件。改变布局需统一修改宏并检查接口。宏重新运行会覆盖同名输出，请先另存需要保留的人工修改。
