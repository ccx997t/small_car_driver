# 第三轮工作计划：连接细化与运动检查

日期：2026-11-16。状态：用户授权开始后，已生成R03整车组合、单模块与升降评审模型；未完成项见《第三轮评审说明.md》。
基线：第二版 R02，本地提交 307ff98。R01、R02文件保留，第三版单独建立。

## 目标与边界

将第二版静态布局推进为能说明“如何固定、如何装拆、如何上下运动”的结构方案。仍保留黑色安装架既有约束；未知接口继续标为待确认。制造路线、材料与正式承载选型不在本轮强行定案。

本轮认可布局或演示运动，不代表实物接口已匹配、弹簧已选型或具备生产条件。

## 已有基础

- 一套驱动模块、局部车架、车架安装法兰、双导向、双弹簧和端部适配座。
- 车内为电机侧、车外为轮毂侧，作为当前设计约定。
- 45个实体几何有效，第二版静态位置未检出超过0.05 mm³的实体重叠。
- 独立FreeCAD配置与桌面启动脚本已建立。

## 增补范围：简化整车组合

第三轮加入简化整车底盘、轮组位置及设备占位，与连接细化同步推进。按新增底盘初稿整理为中部左右两驱动轮、前后四轨道轮、四万向轮和双圆管轨道；尺寸按初稿资料记录，非实测定稿。整车外形尺寸和真实车架接口不足时只表达布局，不宣称实车匹配。模块局部坐标与整车坐标分开管理，明确两侧电机均朝内。

## 工作顺序

| 优先级 | 工作 | 第三轮具体结果 |
|---|---|---|
| P0 | 黑色架与端部适配座的连接 | 明确承托面、定位面、防脱方向、压紧件及紧固路径；优先不改原件。暂定夹持方案须标注，不能把未知孔当作已知安装孔 |
| P0 | 固定支座及导向轴固定 | 补足轴端锁紧、轴套保持、弹簧座固定、限位环锁紧；说明车架法兰螺栓如何安装、如何接近螺母或螺纹件 |
| P0 | 随动部件分组 | 轮、电机、原架、适配座及活动弹簧座作为共同随动部分；固定支座、轴端固定件归入固定部分 |
| P1 | 弹簧和上下限位协调 | 定义示意中位、上压、下伸位置；按几何与弹簧安装长度提出暂定演示行程，不将R02约8mm间隙直接当作额定行程 |
| P1 | 运动检查 | 提供上限、中位、下限视图，并沿暂定行程采样检查；明确接触、允许配合与非预期相交的区别，记录采样间隔和结果 |
| P1 | 双轴导向误差补偿 | 比较补偿式轴套/浮动座与可调安装方案，选择可表达的方案；未完成的补偿结构不得仅靠命名宣称已实现 |
| P2 | 线缆与维护空间 | 加入固定端/活动端线夹、弯曲空间和接插件包络；检查电机与轮拆出路径、紧固件工具空间 |
| P2 | FreeCAD模型整理 | 统一参数来源，减少代码中的重复尺寸；关键布局与行程尽量联动，注明仍由宏生成的独立实体 |

## 未知数据的处理

| 数据 | 对本轮的影响 | 无数据时的处理 |
|---|---|---|
| 原架端部孔/开口用途 | 影响端部适配与导向结构 | 保持待确认；以不改原架的可拆适配方案表达，不证明实物可装 |
| 原架外形、中央接口、孔距、厚度 | 决定真实装配匹配 | 沿用近似形体，尺寸注明暂定；不得输出制造定稿 |
| 真实车架截面、壁厚、孔位、可用空间 | 决定法兰与紧固方式 | 局部车架保留为设计包络，不假定可在实车任意钻孔 |
| 弹簧示意与实物关系 | 影响结构沿用程度 | 作为方案参考，不认定已对应 |
| 轮分担载荷、行程、场地及速度 | 决定弹簧、导向、限位和动态表现 | 只做几何演示，不给出正式刚度、预压或承载结论 |

若方便补资料，优先取得原架正面/侧面及一个可靠尺寸、车架安装区近照和接口尺寸；不要求先一次性提供全套数据。一个基准尺寸只能辅助比例估计，不能据此认定其他孔位具有工程精度。

- 几何有效性及运动采样检查记录；未解决问题清单。

## 本轮验收

1. 关键连接能说清固定方式，不再仅靠形体贴合表达可靠连接。
2. 固定与随动关系清楚，演示位置和暂定行程有明确说明。
3. 暂定行程的检查方法、非预期相交及未覆盖项均有记录；离散采样不宣称证明连续全行程安全。
4. 原架约束没有未经允许的大幅修改；所有未实测接口与尺寸仍明确标识。
5. FreeCAD可打开、显示、重算；第二轮模型保持不变。

推荐推进顺序：先做端部适配和轴端固定，再做限位与运动，最后整理线缆与展示。整车仅做布局必要的底盘与设备占位，不先做装饰外壳和上部设备详细建模。
